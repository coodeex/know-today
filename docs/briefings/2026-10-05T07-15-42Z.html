October 5, 2026
Connected agents Agent skills Browser automation Knowledge workflows Multi-agent coding Access controls

👀 Keep an eye on

  • Connected co-work agents are shifting evaluation from prompt quality to whether an agent can complete a workflow across business applications.
  • Successful runs can be captured as reusable skills, turning local preferences for structure, formatting, and outputs into operating assets.
  • Browser-driven document handling makes invoice submission and other back-office work plausible automation targets, but authority and audit design now matter as much as model capability.
  • Coding-oriented agent environments are emerging as a separate execution surface for ambitious changes that need coordinated subagents.

🧭 What changed

  • Execution surface: agents can retrieve context from connected systems and produce deliverables without manually assembling every input in chat.
  • Reusable procedure: a refined interaction can become a skill, reducing repeated prompt negotiation for recurring work.
  • Reference-led setup: an approved prior report, deck, or invoice package can define “good” without training a custom model.

💭 Opinions worth testing

  • Opinion: Agents are now useful for meaningful portions of knowledge work, not just question answering.
  • Opinion: The highest-value early targets are recurring tasks that vary too much for conventional automation but consume too much human effort to leave manual.
  • Opinion: Reviewing a team’s calendar is an effective way to find repeated work worth delegating.
  • Opinion: Agents should be introduced with the same scoped instructions and access discipline used for an inexperienced new hire.
  • Opinion: Capturing a successful workflow as a skill is more valuable than recreating a long prompt conversation each time.
  • Opinion: Co-work interfaces will become the normal way many people use agents, blurring the boundary between chat and execution.
  • Opinion: Coding agents are better suited to software changes and multi-agent work, while co-work agents fit broad knowledge workflows.
  • Opinion: Consequential performance-management work still requires human judgment and ethical responsibility even when agents handle research and checklists.

Reflection: Inventory repeated work. Collect approved exemplars. Encode accepted procedures as skills. Separate operational authority from consequential judgment.

🔮 Predictions to track

  • Prediction: Connected, action-capable workspaces will increasingly replace separate chat and execution modes.
  • Prediction: Agent skills will become portable across products, making internal procedures a vendor-neutral asset.

Reflection: Design procedures independently of one interface. Store examples and acceptance criteria with each skill. Test portability claims across target platforms.

🚀 Build something ambitious

Operations execution fabric

Outcome: Give an operations team a system that completes recurring document-heavy work while producing a durable record of how decisions and exceptions were handled.

Workflow: Ingest requests from email or a work queue, retrieve files and system context, classify the job, execute browser and application steps, validate the final package against approved examples, submit within delegated authority, and route exceptions to an accountable operator.

Connected capabilities: Connected files, email, browser automation, document extraction, structured validation, policy-aware authorization, audit logs, and a skill library that improves from accepted runs.

First meaningful milestone: Automate the complete monthly invoice-package flow for one business unit, including retrieval, extraction, submission, exception routing, and measured handling time.

Institutional skill operating system

Outcome: Convert high-performing team workflows into reusable agent capabilities that preserve company-specific standards as the organization scales.

Workflow: Pair each recurring task with approved examples and acceptance criteria, refine an agent run through real output feedback, publish the resulting skill with scoped tools and ownership, measure downstream quality, and update the procedure when outcomes expose a gap.

Connected capabilities: Agent workspaces, retrieval over reference artifacts, structured output checks, shared skill distribution, coding agents for technical tasks, and outcome analytics.

First meaningful milestone: Publish ten production-used skills across operations, sales enablement, and engineering, each with an exemplar, explicit authority boundary, and quality metric.

⚡ Fast builds to try

  • Calendar-to-delegation map: Export one week of recurring meetings, group the repeated preparation and follow-up work, and get a ranked list of concrete agent candidates.
  • Gold-standard artifact pack: Gather three approved reports or decks for one recurring job and annotate their required sections, producing a practical agent brief.
  • Skill capture template: Turn a successful AI-assisted deliverable into a one-page procedure with inputs, output checks, tool access, and exception conditions.
  • Execution-surface comparison: Give one documentation task and one code change to the appropriate agent environments, then compare completion quality and intervention effort.

⚠️ Caveats

  • Verify product claims: reported interfaces, connectors, plans, security properties, and skill portability may differ by deployment and require current documentation.
  • Treat savings anecdotes carefully: headline time reductions do not establish reliability, exception rates, or total operational effort.
  • Design authority explicitly: workflows that enter third-party systems or submit financial items need access controls, segregation of duties, auditability, and clear escalation conditions.

🧠 The author's perspective

The author believes that the day’s shift toward connected co-work agents, reusable skills, browser execution, and multi-agent coding directly aligns with a future in which people operate increasingly autonomous companies through durable instructions, capable runtimes, integrations, data, and delegated authority. In this interpretation, accepted outputs and reference artifacts become the decision data that lets agents learn organizational standards, while scoped access, explicit evaluation, and exception escalation make broader end-to-end loops possible across research, implementation, operations, and deployment. The emerging distinction between knowledge-work execution surfaces and coding-agent environments also supports the idea that orchestration will coordinate specialized agent groups rather than rely on isolated chat tasks.
