👀 Keep an eye on

  • Coordinator-led coding workspaces can dispatch parallel cloud sessions on separate branches while preserving a main steering conversation.
  • Routed multi-model systems make verification and selective escalation a product capability rather than an invisible infrastructure choice.
  • Persistent project memory is becoming a meaningful differentiator for long-running agentic software work.
  • MCP-connected generation makes voice, music, image, and video creation callable from an existing agent workflow.
  • Outbound voice agents are moving routine business calls, wait times, and appointment booking into automatable operating work.

🧭 What changed

  • Coordinated coding: a project can hold repository context, a central coordinator, and individually steerable implementation threads.
  • Grounded learning: notebooks can become conversational interfaces to captured material, with audio capture and interactive study formats emerging.
  • Long-context multimodality: a new multimodal model is positioned for video, music, audiovisual summarisation, and real-time conversation with a claimed one-million-token context window.
  • OS-level assistance: screen awareness, cross-app context, and task execution are being tested as a personal-assistant pattern.

Availability note: several capabilities remain beta, selective, staged, or waitlisted; verify access, geography, and production behavior before designing around them.

💭 Opinions worth testing

  • Opinion — Coordinator-plus-thread project structure is a more natural shape for complex AI-assisted software work than a single monolithic chat.
  • Opinion — Vendor launch language is not operational evidence when paid users still lack access to the announced capability.
  • Opinion — Conversational notebooks paired with lecture capture could turn passive learning material into a durable question-and-answer system.
  • Opinion — Fast and token-efficient routed-model results are unconvincing until model selection, cost, latency, and evaluation outcomes are attributable.
  • Opinion — Alignment, evaluation, and governance deserve investment alongside product capability even when extreme-risk forecasts are uncertain.
  • Opinion — A lab pausing a release for safety can be a meaningful governance action independent of regulation.

Reflection: Design work around coordinated branches. Demand attributable routing metrics. Verify launch access. Fund evaluation capacity.

🔮 Predictions to track

  • Prediction — Central coordinators will increasingly dispatch parallel specialist threads for agentic projects.
  • Prediction — Voice agents will become useful for routine business interactions such as booking appointments and staying on hold.
  • Prediction — Broad media workflows may gain a practical long-context multimodal option once independent testing and provider access arrive.

Reflection: Instrument branch concurrency. Map repeatable call flows. Benchmark multimodal pipelines. Track reliable access.

🛠️ Practical workflows

  • Branch-per-thread development: give a coordinator the objective and repository context, dispatch discrete implementation threads, then measure merge conflicts, defects, review load, and elapsed time.
  • Verified model routing: route routine work to efficient models, invoke stronger models for hard cases, and record the selected model, checks, token use, latency, and cost per outcome.
  • Multimodal production chain: let an agent generate draft narration, audio, visuals, and video through connected tools, then enforce spending limits, output checks, provenance, and publication authority.

⚠️ Caveats

  • Claims around benchmarks, efficiency, and model identity need independent reproduction.
  • Persistent memory can preserve stale assumptions unless teams can inspect and correct it.
  • Voice calling, screen context, and cross-app actions create material identity, privacy, consent, and authorization obligations.
  • Tool-connected media workflows need explicit authority boundaries before autonomous publication.

🚀 Build something ambitious

Autonomous software delivery desk

Outcome: a small product team ships more customer-requested work without expanding coordination overhead. Workflow: ingest customer signals and repository context, convert validated requests into planned work, dispatch branch-isolated coding agents, run tests and review checks, escalate ambiguous product or security decisions, and feed release outcomes back into prioritisation. Connect: a coordinator runtime, coding agents, durable project memory, CI, issue tracking, model routing, and evaluation logs. First meaningful milestone: deliver a week of independently planned and implemented low-to-medium complexity changes with measured quality, cycle time, and intervention reasons.

Media-to-knowledge operating system

Outcome: teams turn meetings, lectures, research, and product calls into a compounding internal knowledge asset. Workflow: capture spoken and visual material, transcribe and structure it, ground a conversational notebook in the collection, generate quizzes and briefings, identify unanswered questions, and route high-value insights into product, sales, and training workflows. Connect: audio capture, long-context multimodal models, retrieval, conversational notebooks, persistent memory, and MCP media tools. First meaningful milestone: make one team’s weekly material searchable and capable of producing cited answers, learning exercises, and a useful decision briefing.

Voice operations agent network

Outcome: service businesses reduce administrative drag while customers receive faster completion of routine requests. Workflow: classify inbound requests, call businesses for bookings or status checks, remain on hold, update the operating system of record, notify customers, and escalate identity-sensitive, unusual, or high-impact conversations. Connect: live voice models, telephony, scheduling, CRM, durable instructions, authorization controls, and outcome evaluation. First meaningful milestone: complete a constrained appointment-booking flow end to end with disclosure, structured records, and tracked completion quality.

⚡ Fast builds to try

  • Build a project-memory ledger: have your coding assistant write a short structured note after each session; get a restart brief that preserves decisions, open questions, and current assumptions.
  • Make a routing scorecard: run the same development tasks through two models and a verifier; get comparable quality, latency, token, and cost data.
  • Create a lecture interrogator: load one recorded talk and its notes into a grounded workspace; get instant study questions and concise concept explanations.
  • Produce a media asset chain: ask an agent to call connected voice and visual generators for a short product explainer; get a reusable draft production pipeline.
