👀 Keep an eye on

  • Scheduled agents can now combine email, calendars, chat, documents, and browser work into a recurring operational briefing.
  • Reusable skills are becoming portable workflow assets that can outlast any single model or interface.
  • Coding agents make narrow internal tools practical for non-engineering teams when the workflow has clear inputs and checks.
  • Computer-use agents can bridge browser-only systems, making permissions and auditability central product requirements.
  • Stable steps in agent workflows can move into conventional code, reducing cost, latency, and output variance.

💭 Opinions worth testing

  • Opinion — The agent harness—tools, scheduling, integrations, and permissions—often matters more than small differences between frontier models.
  • Opinion — A small portfolio of well-scoped agents is easier to evaluate and improve than one universal assistant.
  • Opinion — Curated context artifacts outperform indiscriminate retrieval from every available document.
  • Opinion — Skills should be improved from recurring failure patterns, not patched after every isolated correction.
  • Opinion — The highest-value AI work is digitally accessible, economically meaningful, and objectively verifiable.
  • Opinion — Embedding AI into existing work surfaces creates more durable adoption than asking people to live in another application.
  • Opinion — A microtool can justify its initial build cost when repeated use compounds time saved and improves process quality.
  • Opinion — AI remains less dependable for high-impact creative judgment than for constrained production work.

Reflection: Standardize on a compact agent stack. Write concise context documents. Measure repeated corrections. Convert stable transformations into code.

🔮 Predictions to track

  • Prediction — Agent interfaces will increasingly sit between people and browsers, completing app workflows through delegated interaction.
  • Prediction — Constrained short-form video workflows will approach one-pass generation before long-form editorial work does.
  • Prediction — Early discussion on fast-moving social platforms will remain a useful leading indicator for topic and product gaps.

Reflection: Instrument agent-mediated browser flows. Separate templated media from editorial work. Monitor emerging demand signals. Compare outcomes against human baselines.

🛠️ Practical workflows

  • Run a scheduled operations agent that prioritizes recent communications, links supporting context, and drafts next actions for an operator.
  • Maintain a skill library with a purpose, inputs, output contract, evaluation criteria, owner, and recurring improvement cycle for every workflow.
  • Route proposed changes to strategy documents, external communications, and consequential code through explicit before-and-after diffs.
  • Use task-specific feedback interfaces—such as timestamped media notes or structured approval queues—where free-form prompting loses precision.

⚠️ Caveats

  • Verify availability: reported model, connector, browser-control, and cloud-execution capabilities may vary by product tier, region, and account.
  • Treat performance claims cautiously: speed, quality, and frontier-access claims are anecdotal rather than controlled comparisons.
  • Govern connected data: email, chat, calendar, and Drive access require clear identity boundaries, retention rules, logging, and escalation conditions.
  • Keep security testing authorized: refusal-weakened models create material misuse risk and require isolated, governed defensive environments.

🚀 Build something ambitious

Autonomous operating desk for a founder-led company

Outcome: turn fragmented communications into an operating rhythm that keeps priorities, commitments, and decisions current. The system ingests email, calendar, team chat, planning documents, and customer signals; a daily chief-of-staff agent produces linked priorities, specialized agents prepare research and drafts, and an advisor agent compares material decisions against a concise company plan. Give each agent a defined authority boundary, track completion and correction rates, and escalate customer-facing, financial, legal, and strategic exceptions to a person. First meaningful milestone: a two-week run that produces a daily linked brief and captures whether its top five priorities were accepted, changed, or completed.

Composable workflow marketplace inside the company

Outcome: make organizational know-how executable and portable instead of trapped in individual chats. Teams publish utility skills, task skills, and orchestration skills with reusable context, deterministic code for stable steps, connected data access, and evaluation fixtures; agents then compose them into operational workflows across existing work surfaces. The feedback loop is correction data, periodic skill analysis, proposed diffs, and measured downstream outcomes. First meaningful milestone: ship five shared skills that serve three teams and demonstrate reuse without duplicating instructions.

Vertical review OS for high-friction creative production

Outcome: compress the loop between a creator, editor, and production system without flattening human taste. A coding agent builds a domain interface for timestamped notes, frame-level references, briefs, and approval states; media agents generate constrained variants while humans retain authority over narrative and high-impact creative choices. The system learns from accepted versus rejected edits and routes ambiguous work to the appropriate specialist. First meaningful milestone: complete ten review cycles in one interface and measure reduction in clarification messages and edit turnaround time.

⚡ Fast builds to try

  • Create a skill-diff reporter: feed it several recent corrections and have it produce numbered proposed instruction changes; get a clean view of recurring workflow failures.
  • Make a browser-task checklist agent: define a form-filling sequence and required evidence before execution; get consistent handoff notes for browser-only work.
  • Build a spreadsheet check-in companion: connect one operating sheet and ask for a weekly anomaly and commitment summary; get a focused meeting agenda.
  • Split one agent flow into code and model steps: identify a repetitive extraction or transformation stage and implement it conventionally; get a faster, more predictable workflow.

🧠 The author's perspective

The author believes that the day’s information aligns with a future in which software development and company operations become increasingly autonomous through capable runtimes, durable instructions, integrations, data, and appropriate authority. Portable skills, composable workflow layers, cloud scheduling, connected operational context, computer use, and coding-agent-built interfaces all support the idea that a harness can coordinate planning, implementation, testing, review, and deployment loops beyond isolated chat tasks. The emphasis on scoped agents, concise strategic context, measured feedback, deterministic code for stable work, and clear escalation conditions also supports an operating model where AI acts by default, learns from outcomes, delegates real-world needs to people, and leaves humans available for consequential judgment.
