🚀 Build something ambitious

Autonomous vertical-slice factory

Outcome: Turn a product thesis into a working, measurable interactive prototype while preserving a comparable record of agent performance.

Workflow: A planner converts a brief into acceptance criteria and milestones; implementation agents build the application; runtime agents exercise it; test and product agents inspect failures and behavior; a coordinator assigns repairs until the artifact meets the defined bar or escalates blocked decisions.

Connected capabilities: Frontier coding models, task planning, isolated execution environments, browser or game-runtime automation, automated tests, static analysis, issue tracking, artifact capture, and an evaluation store.

First meaningful milestone: Produce three independently built vertical slices from one specification and compare their completion quality, cost, elapsed time, test pass rate, and human escalations.

Living coding-agent benchmark network

Outcome: Make model selection a compounding operational advantage rather than a periodic opinion.

Workflow: Maintain a portfolio of realistic end-to-end tasks; dispatch each to candidate models under equivalent tool authority; collect executable artifacts and quality signals; route future work by task type; feed production outcomes back into the benchmark set.

Connected capabilities: Multi-model orchestration, repositories, CI tests, security scanning, cost telemetry, artifact review, routing policy, and durable task specifications.

First meaningful milestone: Establish a weekly scorecard that changes routing for at least two real development task classes using measured results.

⚡ Fast builds to try

  • Make a one-hour game mechanic: ask a coding agent to implement one complete loop with automated checks; get a concrete signal on execution quality rather than chat quality.
  • Create an agent run ledger: log task, model, duration, cost, interventions, and test outcome for each run; get a usable basis for routing decisions.
  • Build an artifact-first review page: collect screenshots, test output, architecture notes, and open defects from one agent run; get a compact decision surface for judging completion.
  • Run a repair-only challenge: give an agent a deliberately broken interactive app and a test suite; get a direct measure of debugging persistence.

🧠 The author's perspective

The author believes that the reported sustained build-and-test behavior aligns with a future in which software development and company operations are increasingly autonomous: capable coding agents can move beyond isolated tasks when a runtime gives them durable instructions, tools, data, authority, and observable evaluation loops. A long-running implementation effort particularly supports the value of harnesses that coordinate planning, implementation, testing, review, and deployment, while artifact-based measurement supports data-driven learning from outcomes. The rapid movement of coding models also aligns with maintaining reusable skills, adaptable orchestration, and systems that can switch contexts and delegate work or request human help when real-world interaction is necessary.
