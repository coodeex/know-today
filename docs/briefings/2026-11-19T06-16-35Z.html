👀 Keep an eye on

  • Spec-and-ticket graphs make it practical to run long agent implementations as coordinated work rather than one open-ended coding session.
  • Persistent video editing across cuts and camera re-shooting point toward editable scenes replacing one-shot generated clips.
  • Full-duplex speech models are arriving through open weights and APIs, but natural conversation must be evaluated separately from factual and task reliability.
  • Agent retrospectives can turn session traces and code-review patterns into durable repository rules, helpers, and skills.
  • Low-cost 3D and robot-learning systems are lowering the cost of testing physical-product workflows outside major labs.

🧭 What changed

Editable media is becoming a workflow

Scene-aware character compositing, world continuations with camera direction, reconstructed 4D scenes, and cross-shot edits all shift generative video toward iteration after the first render.

Agent work is acquiring operating discipline

Domain interviews, glossaries, decision records, disposable prototypes, implementation specs, dependency-aware tickets, and retros form a repeatable execution environment.

Compute is becoming an adjustable creative input

Image-to-3D generation can expose a token budget that trades speed and memory for fidelity, enabling cheap drafts before expensive output.

💭 Opinions worth testing

  • Opinion: Domain language is an implementation tool because names shape data models, modules, and user-facing behavior before code exists.
  • Opinion: Prompts should begin with the desired outcome and underlying problem, leaving room for agents to propose better implementations.
  • Opinion: Agent autonomy should shrink from discovery to implementation as prototypes, specs, and tickets remove consequential ambiguity.
  • Opinion: Rejected interface prototypes are valuable requirements evidence rather than wasted exploration.
  • Opinion: Smaller, relevant contexts and fresh specialist agents can outperform sprawling historical context for debugging and implementation.
  • Opinion: Code review should upgrade the system that produced a change by converting recurring findings into checks, typed APIs, or shared utilities.
  • Opinion: Open world models are strategically useful for previsualization and optionality even when their output is not ready for final production.
  • Opinion: Realistic voice interaction requires separate safeguards for consent, identity, escalation, and impersonation resistance.
  • Opinion: Mature canvas platforms can remove substantial interaction-engineering work through built-in state, compositing, and unified undo primitives.

Reflection: Build a project glossary. Require competing prototypes. Capture acceptance criteria in tickets. Convert repeated review findings into constraints. Benchmark fresh agents against long-context sessions.

🔮 Predictions to track

  • Prediction: Agent retrospectives will produce a continuing queue of small repository improvements that agents can execute with minimal coordination.
  • Prediction: Comment audits will become a reusable maintenance skill that identifies workaround-heavy code for redesign or explicit documentation.
  • Prediction: Model and runtime advances will reduce the operational burden of keeping signal intact across large contexts.
  • Prediction: Live, glasses-based AR interaction is a plausible direction for scene-aware character systems, though current experiences are post-rendered.
  • Prediction: Combining affordable motion hardware, conversational models, and phone-based robotics could enable compelling DIY physical agents, with substantial integration work remaining.

Reflection: Track release maturity. Measure context efficiency. Maintain a backlog from retrospectives. Watch for independent hardware tests.

🚀 Build something ambitious

Autonomous product-delivery operating system

Outcome: Let a lean product company turn validated customer problems into shipped, measurable product increments while preserving engineering intent and institutional learning.

Workflow: A discovery agent interviews stakeholders and mines product evidence; a design agent produces competing interactive prototypes; a planning agent writes a glossary, decision records, spec, and dependency graph; implementation agents complete isolated tickets; verification agents test against acceptance criteria; a release agent prepares staged activation; a retrospective agent converts traces and review findings into repository improvements. Humans supply taste at key design cruxes and handle escalations involving authority, customer commitments, or novel risk.

Connected capabilities: Coding agents, issue tracking, prototype canvases, source control, test runners, feature controls, product analytics, customer feedback, durable project memory, and structured agent traces.

First meaningful milestone: Ship one complete feature through the system with a traceable chain from customer evidence to prototype, spec, tests, production metrics, and a retrospective-generated improvement backlog.

Editable synthetic production studio

Outcome: Give small teams the ability to produce product demos, training sequences, and campaign footage by directing scenes rather than rebuilding each edit manually.

Workflow: Ingest real footage or product references, create low-cost 3D and scene drafts, generate alternate camera paths and character interactions, carry approved visual edits across cuts, then route output through continuity and artifact checks before final compositing. Feedback on accepted shots becomes a reusable scene and style library.

Connected capabilities: Image-to-3D generation, video reconstruction, camera-path tools, world models, video editing models, asset management, rendering infrastructure, and review annotation.

First meaningful milestone: Produce a 20-second product story with three editable camera treatments from one captured scene and document quality, latency, compute cost, and failure patterns.

Voice-and-vision field operations layer

Outcome: Help distributed service teams capture work context, guide physical procedures, and improve operating knowledge without turning every interaction into a form.

Workflow: A worker speaks naturally while documenting a task; the system handles interruptions, pairs notes with visual evidence, proposes the next procedural step, and escalates uncertain, safety-sensitive, or identity-sensitive situations. Completed work generates searchable training examples and updates operational playbooks from measured outcomes.

Connected capabilities: Full-duplex voice, mobile cameras, workflow orchestration, retrieval over procedures, structured task records, identity and consent controls, analytics, and human escalation.

First meaningful milestone: Complete an end-to-end field procedure where voice capture produces a verified task record, evidence bundle, exception queue, and reusable playbook update.

⚡ Fast builds to try

  • Context reset benchmark: Give a fresh coding agent and a long-running agent the same defect; compare time, test quality, and unnecessary changes to identify the better handoff point.
  • Three-way interface sprint: Generate three disposable interaction variants for one uncertain workflow; collect reactions and leave with concrete language for the winning design.
  • Interruptions test rig: Build a short scripted conversation with barge-ins and corrections; run it against a voice model and leave with measured latency and recovery behavior.
  • Compute-quality asset ladder: Create the same 3D object at three token budgets; record memory use, generation time, and visual acceptance for a practical default.
  • Review-pattern miner: Feed recent review comments into an agent; extract repeated defects and leave with candidate lint rules, helpers, or documentation changes.

⚠️ Caveats

  • Verify availability and licensing: several compelling media and voice capabilities remain research demonstrations, limited previews, or specialist local workflows.
  • Treat natural voice as high-risk: conversational realism can increase impersonation and consent risks even when task reliability is weak.
  • Demand task evidence: robotics and generative-media claims often lack enough benchmark, environment, cost, and failure-rate detail for deployment decisions.
  • Protect implementation quality: large agent-generated changes depend on maintained project context, tests, release discipline, and explicit authority boundaries.

🧠 The author's perspective
